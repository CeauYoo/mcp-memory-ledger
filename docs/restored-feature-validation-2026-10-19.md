- 显式模型经验草稿：Chat Completions、Responses、Anthropic 共享严格输出合同；先保存尝试、再调用模型，重放不重复生成，候选始终 pending。

- Schema 10 适用性声明：明确有效区间、条件及环境，不从记录时间推断有效时间；权威声明与可删除的派生向量缓存分离。
- 宿主可配置 literal / enhanced / hybrid 任务续接，硬要求优先；可选召回共用截止时间，不能宣称同步计算可被强制抢占。
- 43 个 standalone 工具、36 个 scoped 工具、7 个禁止的全局入口。原界面风格保持不变。

使用方式见[草稿合同](experience-model-drafts.md)、[增强检索](enhanced-recall.md)、[中文配置](retrieval-config.zh-CN.md)和[本地向量](local-embeddings.md)。配置默认兼容；启用 hybrid 需显式启用本地 embedding、填写模型摘要和精确 namespace 白名单。`retrieval cache-rebuild` 重置派生缓存，之后的已授权使用才重新生成向量，不会批量调用真实模型。

## 修复与审查边界

- macOS 备份 fixture 使用 canonical 临时目录，生产符号链接拒绝逻辑未放宽。
- 正常桥接测试在启动后立即握手，避免未初始化连接等待及注册表变更窗口；错误诊断仅捕获合成子进程有界 stderr。此前 Windows pipe-closed 的确切原因仍未被证明。
- 独立静态检查发现并修复了新读取的字节/类型预算、缓存 checksum 的嵌入 NUL 长度绕过、词面候选变化后继承旧排名等问题。
- 该审查仅覆盖新增实现，不是全面安全认证。旧下游回执/依赖读取仍有损坏数据库下的历史限制；校验和不是抗恶意篡改认证；loopback 地址不能证明本地服务不向云端转发。
