# Proposed Collaboration Guidelines

These are draft collaboration guidelines for this technical demo / MVP. They provide a proposed review baseline; they do not announce a staffed enforcement team, a response deadline or an already adopted organization-wide policy.

Participants are asked to:

- Discuss the work respectfully. Critique claims and implementations, not people; avoid harassment, threats and discriminatory abuse.
- Respect privacy and consent. Do not post another person's private information, credentials, memories or private conversations.
- Describe evidence honestly, including failures and uncertainty. Do not present a mock test, a proposal or an unverified release as proven behavior.
- Keep discussions relevant and allow maintainers to clarify scope, decline a proposal or request a smaller reproducible example.

Maintainers reviewing activity in this repository can use these guidelines when requesting edits, redirecting a discussion, closing a thread or restricting repository participation through the platform's available controls. Decisions should be proportionate and explained where doing so does not expose private information. No authority over activity outside this repository is claimed.

For a concern involving sensitive details, first verify a private contact channel with a maintainer; do not post those details publicly. Security concerns follow [SECURITY.md](SECURITY.md). If no private channel is established, a public request may ask only how to contact a maintainer privately. Do not name an unconfirmed contact or assume a guaranteed response time.

The scope, adoption and handling process for these draft guidelines may be clarified in a reviewed repository change.
