Memory Ledger · 定向后全量体验复测

入口：仓库根目录执行 python3 -E -s -B tools/experience/run.py；macOS可双击 Start-Retest.command。
需要Python 3.10+和已构建的target/debug/agent_llm_mm（Windows为.exe）。缺少二进制时先自行运行 cargo build --bin agent_llm_mm；工具不会安装软件。
只隐藏输入一次key即自动开始，无SEND、模型别名或逐轮确认。不要把key放进命令行、文件、聊天、环境变量或Git。
模型请求保持 gpt-5.6-luna，目标 https://yooyui.chat/v1/responses；返回名称只记警告，不能认证模型身份。

执行顺序：
1. S16/S19/S23/S25各3轮，共12轮，覆盖4个问题轮次及相邻对话。
2. 定向阶段首次客观、正文日期、协议或存储失败即停止，不进入全量；不能自动重跑。
3. 定向自动检查无失败后，继续完整30场景×3轮。自动门不代表正文语义已经验收。
正常102次请求，两阶段共享最多10次显式重试，总发送不超过112次；每轮最多重试一次。
每次完整序列化输入最多256KiB；输出按场景2304/4096/4608 tokens；响应最多4MiB；读取限时180秒。
只对临时网络失败、短响应、429/502/503/504显式重试；认证、权限、余额不足立即停止。
保留默认代理/TLS，禁止重定向，无SDK隐式重试。每次先持久预留并独占写记录，再发送。
子run开始前登记位置；收尾落盘异常时总次数标未知，并保留已知下界，不能误报为零或免费。

实时监控：
输入key后、首个模型请求前，会自动打开 http://127.0.0.1:<自动端口>/，终端打印准确地址。
这是运行中的HTTP服务，每秒读取当前阶段、逐轮状态、请求次数、用量和延迟；两个实例不会争抢固定端口。
只提供 / 和 /api/status；不暴露key、完整对话、诊断文件或SQLite；Host校验、无CORS、禁止文件目录服务。
结束后监控保持最终状态，按Ctrl+C关闭。此时不会再发模型请求，也不会占用并发运行锁。
完整逐轮静态报告另存本地，不能替代运行监控。
正式MCP程序仍有独立的Memory-chan Live Desk：dashboard.enabled=true时随serve启动，默认127.0.0.1:8787，页面每2.5秒刷新。
本体验工具每轮重启MCP进程，故MCP配置关闭其单进程dashboard；统一进度页由独立的本机只读监控服务提供。

费用与凭据：
使用服务商侧5美元总额度（包含此前消耗），价格未知，软件不能保证美元封顶。
每次usage分别保存，缺失保持null；reasoning是output明细，不重复加总。cost_usd仅为未独立核验的服务端自报。
无余额查询权限，不读取旧key。助手只能执行 --rehearse / unittest等离线合成检查；真实调用由用户交接key并触发。

证据与评分：
每轮真实MCP写入/检索/来源/更正/历史核对；每轮新MCP进程，新会话还清空模型历史和背景。
同会话后轮携带真实前轮文本，包括错误回答，绝不注入预期答案替换前轮。
项目名称绑定仅含当前namespace且标注来自合成客户端选择，不把其他项目内容加入。
引用ID、量值、单位字段、状态、namespace和来源事件严格核对；不能交换同轮其他Claim的来源。
仅在指定decisions字段接受有限等义表示，矛盾后缀、错误日期/时区仍失败。
S16明确固定准备起点；正文日期检查只拒绝该任务中的显式过期或非法日历日期，不能检验所有自然语言、未写年份或含糊排期。
所有正文仍需人工语义复核。结构核验通过不证明正文正确、引用因果有效或模型自主提取记忆成功。
长档案1.2万—3万字符含过期草案与相似实体；关键事实亦出现在MCP或用户问题，不能声称唯一事实位置检索能力。

输出：默认 target/experience-acceptance/（Git忽略）。runs保存每次独立数据库、摘要、完整本机诊断和冻结代码；staged保存阶段计划与汇总。
Authorization不记录；常见凭据字段和已知key/编码回显脱敏。完整记录仍必须仅存本机，不能以自动脱敏作为上传许可。
POSIX文件设置0600；Windows的chmod/st_mode不证明仅当前用户可读，访问限制由所选输出目录的Windows ACL决定，本工具不修改系统ACL。
不提交run、SQLite、key、原始日志或二进制；可共享人工整理的聚合报告。原始实测和以前入口不被覆盖。
本工具默认二进制哈希只证明文件身份；未提供构建receipt时不声明源码绑定或新机器验收。
